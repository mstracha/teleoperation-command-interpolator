# Acknowledgments

Mark Strachan is the author and maintainer of the Teleoperation Command Interpolator.

The system design, C++ implementation, behavioral tests, build packaging, and documentation were developed collaboratively with OpenAI Codex. Mark directed the architecture and safety priorities, reviewed the work incrementally, ran each build and test gate, and made the project-level decisions represented in the final design.

The project also reflects general techniques from robotics controls, real-time programming, numerical trajectory generation, concurrent data structures, and evidence-driven software verification. No external project is represented as having certified or endorsed this implementation.
